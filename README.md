# Quiz matematica – Classe quarta

Progetto didattico per trasformare la prova d'ingresso di matematica di classe quarta in un quiz digitale interattivo.

## Stato attuale
- pagina alunni dimostrativa
- grafica adatta a PC/tablet/LIM
- correzione locale di una parte degli esercizi
- area docente dimostrativa
- struttura pronta per GitHub Pages

## Prossimi passi
1. completare tutti gli 11 esercizi della prova d'ingresso;
2. collegare un database (es. Supabase) per salvare risposte e punteggi;
3. proteggere l'area docente con autenticazione;
4. pubblicare il sito con GitHub Pages.

> Nota: GitHub Pages esegue HTML/CSS/JavaScript, non PHP.
